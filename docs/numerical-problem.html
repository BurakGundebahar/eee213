Problem 7 · Weeks 6–7 methods

Non-linear resistor network

Two node voltages of a DC circuit with cubic non-linear resistors, found with multivariable Newton–Raphson. Solved in Week 11

Model and assumptions

A DC source Vs feeds node 1 through resistor R1. Resistor R2 joins node 1 and node 2. Each node is connected to ground through a non-linear (varistor-like) resistor with current I = K·V³.

  • Steady DC state; ideal source and wires.
  • Linear resistors obey Ohm's law.
  • The non-linear characteristic is exactly cubic and does not depend on temperature.
  • Node voltages are positive.

Governing equations

Kirchhoff's current law at each node (every term in A):

f1 = (V1 − Vs)/R1 + K1·V1^3 + (V1 − V2)/R2 = 0
f2 = (V2 − V1)/R2 + K2·V2^3              = 0

Jacobian, derived by hand (A/V):

J = | 1/R1 + 1/R2 + 3·K1·V1^2      −1/R2               |
    | −1/R2                         1/R2 + 3·K2·V2^2   |

Newton step:  J·ΔV = −f,   V_new = V + ΔV

Method

Multivariable Newton with the 2×2 Jacobian above. The two KCL equations are coupled and non-linear, so they must be solved together; Newton converges quadratically near the root. Start: V1 = V2 = 1 V. Stop: |ΔV| < 10⁻⁹ V.

Planned independent check

From f2, V1 = V2 + R2·K2·V2³. Substituting into f1 gives one equation in V2, solved by bisection on 0–10 V. Both methods must agree, the KCL residuals must be near zero, and the source power must equal the total dissipated power.

Iteration table, results and the check will be added in Week 11.
